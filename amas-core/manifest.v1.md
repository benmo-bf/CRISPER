# AMaS 记忆引擎 — 不周山模组包

**名称：** AMaS 仿生记忆引擎  
**版本：** v1.0（首发版）  
**兼容：** OpenClaw 3.x +  
**分类：** 核心引擎模块

## 安装说明

本模块为不周山启动器的核心组件。安装方式：
1. 将本ZIP包拖入不周山启动器窗口
2. 方案对比引擎自动检测当前Agent状态
3. 确认安装 → 自动备份 → 原子化安装 → 生效验证

## 模块清单

| 路径 | 说明 |
|------|------|
| `core/agent_memory/` | AMaS核心Python模块（~4600行） |
| `seed_memory/` | 初始记忆框架模板 |
| `patches/` | （预留）补丁扩展槽位 |
| `patches/安装须知.md` | AI安装代理须知-直接跳转README.md |
| `AMaS_不周山_专利说明书.md` | 发明专利说明书（v1.0） |

## 核心能力

- 🧠 三层记忆存储（短期日记→长期→专题）
- 🔄 夜间记忆巩固引擎（海马体→新皮层模型）
- ⚡ 条件反射引擎（快系统+反向学习）
- 🏷️ 标签索引网络（横×竖多维检索）
- 🌱 种子记忆网（初始化模板）
